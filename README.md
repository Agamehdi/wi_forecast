# WI Forecast — GitHub / Streamlit Cloud

**Upload these two files to the root of your GitHub repository:**
- `app.py`
- `requirements.txt`

No folders or additional files are required for running the app. The original `wi_forecast` package is embedded (without modifying its functionality) inside `app.py`.

## Upload to GitHub
1. Open your repository on github.com.
2. Click **Add file → Upload files**.
3. Select **app.py** and **requirements.txt** from this ZIP after extracting them. **Do not upload the ZIP itself.**
4. Click **Commit changes**.

## Deploy
1. Visit https://share.streamlit.io/ and create a new app.
2. Choose this repository and the branch you committed to.
3. Main file path: **app.py**.
4. Deploy.
5. Upload your workbook using the app's interface. It is not stored in GitHub.

Note: if you already have an older app.py in the repository, select **Replace** / upload same name or edit it with these new contents.
